# 这是谁？ / Who's That?

一款使用真实 AlterU 联系人头像的社交身份推理游戏：只展示目标照片的 18%，玩家从三位朋友中认出本人；猜错后逐步显影，最快认出会成为一句克制的正向好友通知。

```bash
npm install
npm run dev
npm run build
```

- 中文 / 英文：`localStorage.game_locale = 'zh' | 'en'`
- 平台外或 `?demo=1`：使用六位明确标记的虚构演示联系人
- 产品、视觉和技术合同：`doc/`
- 制作期生图来源：`_production/`
- 双视口证据：`_qa/ui/`

本作是“五类轻量游戏模板”计划中第二类“社交身份推理”的第一个验证样片。
