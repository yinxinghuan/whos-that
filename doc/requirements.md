# 《这是谁？》需求文档

## 1. Overview

一款 45–75 秒完成一次的竖屏社交身份推理游戏：系统从玩家真实 AlterU 联系人中选出三位候选，只展示目标头像的 18% 局部，玩家在三次机会内认出朋友；答错会扩大线索，结算把“我只看这么一点就认出了你”变成一次克制的好友通知。

本作是第二类“社交身份推理”的第一个样片，验证头像识别、候选干扰、渐进揭晓、资料回流与通知节流。头像必须是谜题主体，而不是 HUD 装饰。

### Interface brief

- 玩家：已有至少三位带头像联系人的 AlterU 用户；平台外测试者进入明确标记的虚构 demo。
- 即时目标：看局部头像，在三位朋友中选出本人。
- 情绪承诺：验证“我真的认得你”，让成功成为对朋友的正向确认。
- 单一主操作：点击一位候选联系人。
- 目标环境：手机竖屏，390×844 与 320×568，Pointer / Touch / Keyboard。
- 信息预算：一张局部照片、轮次、当前揭露比例、三位候选；不显示案件档案、排行榜或长教程。

## 2. Visual Design

- 视觉采用“暗房联系印样”：暖灰照片纸、黑墨编号、朱红裁切标记与钴蓝交互色。
- 主画面 56%–62% 高度由一张大头像占据；黑色剪影层承载人物轮廓，上方只露出 18% / 44% / 76% 的真实照片带。
- 三位候选固定为头像 + 名字的宽按钮；头像 48–56 px，按钮高至少 60 px。
- 答对时遮片在 280 ms 内完全打开，闪光灯白场不超过 90 ms，并出现一张简短“18% 就认出”印样标签。
- 平台外 demo 使用六位虚构成年人的正式生成头像；产品模式只使用真实联系人 `head_url`。
- 完整视觉系统、状态和反模式见 `doc/visual.md`。

## 3. Game Mechanics

### 联系人池

- 通过平台联系人接口读取 `telegram_id`、`name`、`head_url`。
- 去除当前玩家、重复 `telegram_id`、空名字和空头像；不带头像的人不能作为目标或干扰项。
- 有效联系人少于 3 位时不开始游戏，显示真实空状态；不得偷偷混入虚构账号。
- 平台外或显式 `?demo=1` 时使用 6 位本地虚构联系人，并显示 `DEMO CONTACTS / 演示联系人`。

### 单局

- 有效联系人为 3–4 位时进行 3 轮；5 位及以上进行 5 轮。
- 每轮目标不重复；从剩余联系人中随机选择 2 位干扰项，三个答案每轮洗牌。
- 初始揭露比例为 18%；第一次猜错后扩大至 44%，第二次猜错后扩大至 76%。
- 正确得分依次为 3 / 2 / 1；第三次选择后必然揭晓，不存在无限失败。
- 错误候选在本轮禁用并加斜线，不换目标；新线索在输入后 180 ms 内开始扩大。
- 正确或第三次选择后，完整头像显影 900 ms，再进入下一轮；玩家可以点击继续提前结束停留。
- 结算显示 `得分 / 满分`、第一次认出数量和最佳识别对象。

### 社交闭环

- 一局最多通知一位联系人：优先选择第一次、18% 就认出的目标；有多位时取最早出现者。
- 没有第一次认出则不发送通知，避免把“猜错了你”变成负面社交信号。
- 通知只发给真实、非自己、非 demo 的目标：`{sender_name} recognized you from only 18% of a photo.`
- 揭晓与结算中的目标头像 + 名字可点击打开本人 AlterU 资料；答题按钮本身只负责作答，不同时打开资料。
- 通知失败不影响结算；即时结果不得等待网络请求。

### 状态模型

```text
boot/loading → cover → round → miss-expand / reveal → next round → result
             ↘ empty / error ───────────────→ retry
```

## 4. Controls

- Pointer / Touch：开始、候选答案、继续、再玩一次使用 `onPointerDown`，同一按下只触发一次。
- 揭晓和结算中的联系人资料按钮使用 `onClick` 调用 `openAigramProfile`。
- Keyboard：Enter 开始/继续；1–3 选择屏幕顺序对应联系人；M 切换静音。
- 所有交互目标至少 44×44 CSS px；页面禁止 iOS 长按菜单、图片拖拽和非编辑文本选择。

## 5. Win / Lose Conditions

- 本作没有传统失败：三次机会后总会揭晓正确身份。
- 单轮成功条件是在第 1–3 次选择中选中目标；积分衡量使用了多少头像信息。
- 单局完成条件为 3 或 5 个不重复目标全部揭晓。
- 空状态必须说明需要至少三位带头像联系人；接口错误提供重试与 demo 入口，不能伪装成联系人为空。
- 结算必须提供再玩一次；真实目标资料入口只在 AlterU 内启用。

## 6. Sound Effects

- 普通按钮：420 Hz 三角波，55 ms，峰值增益 0.055。
- 错误选择：180 Hz → 120 Hz 正弦下滑，130 ms，峰值增益 0.07。
- 线索扩大：窄带噪声扫过 160 ms，模拟暗房遮片滑动，峰值增益 0.035。
- 正确认出：620 / 820 Hz 两音上行，各 90 ms，间隔 65 ms，峰值增益 0.07。
- 完整显影：980 Hz 极短闪光音 45 ms；第一次认出额外叠加 1240 Hz，80 ms。
- 结算：520 / 660 / 880 Hz 三音，单音 110 ms，间隔 85 ms。
- 首次用户输入后才创建或恢复 AudioContext；静音和音频失败均不阻塞游戏。
